# M Tours — Luxury East African Expeditions

An immersive, single-page luxury tourism experience powered by a high-performance scroll-driven background video frame engine.

## Overview
- **Frame-Scrubbing Canvas Engine:** 876 continuous high-definition frames synchronized with smooth 60 FPS momentum lerp.
- **Single-Page Architecture:** Smooth anchor navigation flowing seamlessly from Hero to Booking.
- **Luxury Glassmorphism UI:** Floating obsidian glass cards, warm gold accents, and responsive layout.
- **Audio Dimension:** Procedural savanna breeze ambience synthesized via Web Audio API.
- **Conversion-Ready:** Instant WhatsApp direct concierge chat and custom itinerary builder.

## Sections
1. **Hero:** Cinematic entrance with brand tagline and primary CTAs.
2. **About Us:** Mission, generational naturalist guides, and trust statistics.
3. **Tour Packages:** Curated safari and flight expedition packages with inclusions and pricing.
4. **Visual Feed:** Authentic moments from the wild (`@_m.tours` Instagram integration).
5. **Why Travel With Us:** Verified 5-star traveler reviews from global guests.
6. **Contact & Booking:** Instant WhatsApp chat and tailored inquiry form.

## Tech Stack
- HTML5 / CSS3 (Vanilla)
- ES6+ Canvas 2D Engine with double-buffering & DPR scaling
- Web Audio API (ambient procedural synthesis)
